## Sobre mí

Estudiante de Ingeniería de Sistemas con enfoque en desarrollo fullstack. Trabajo principalmente con TypeScript, Node.js y React, apoyándome en bases de datos relacionales y no relacionales según el problema. Me interesa escribir código claro, mantener buena estructura de carpetas y entender cómo se despliega lo que construyo.

Actualmente estoy construyendo proyectos propios para consolidar mi stack y aprendiendo nuevas herramientas del ecosistema backend y DevOps.
